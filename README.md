# **Проект Project_E-commerce**

## *Описание:*

Реализация системы платежей для интернет-магазина.

В проекте реализована функциональность сложения стоимости товаров только из одинаковых классов продуктов, что не
позволяет сложить объекты разных классов. При попытке сложения таких экземпляров выбрасывается ошибка TypeError.

Реализован метод, который добавляет новый продукт в категорию таким образом, чтобы не было возможности добавить вместо
продукта или его наследников любой другой объект.

## *Установка:*

Для работы с проектом, необходимо:

1. Выполнить клонирование репозитория:
   git clone https://github.com/MishchenkoElena/Project_E-commerce

2. Установить зависимости:
   pip install - r requirements.txt

## *Использование:*

***1. Класс Product в модуле src.products.py***

Данный класс представляет шаблон для создания товара со следующими
атрибутами:

- название (name),
- описание (description),
- цена (price),
- количество в наличии (quantity).

гзпкфвувВ цепочку наследования класса Product добавлен класс-миксин PrintMixin.

***2. Класс Category в модуле src.products.py***

Данный класс представляет шаблон для создания категории товаров со следующими
атрибутами:

- название (name),
- описание (description),
- список товаров категории (products).

***3. Класс Smartphone в модуле src.product_smartphone.py***

Является наследником класса Product, расширен атрибутами: производительность (efficiency), модель (model), объем
встроенной памяти (memory), цвет (color).
Наследует все свойства абстрактного класса BaseProduct

***4. Класс LawnGrass в модуле src.product_lawn_grass.py***

Является наследником класса Product, расширен атрибутами: страна-производитель (country), срок прорастания
(germination_period), цвет (color).
Наследует все свойства абстрактного класса BaseProduct

***5. Класс BaseProduct в модуле src.base_product.py***

Является базовым абстрактным классом и родительским для класса продуктов

***6. Класс PrintMixin в модуле src.print_mixin.py***

Класс-миксин, который при создании объекта будет выводить в консоль информацию о том, от какого класса и с
какими параметрами был создан объект. Добавлен в цепочку наследования класса Product.
